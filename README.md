# Employee Management System (EMS)

A C# Windows Forms Employee Management System using SQL Server to manage employees, salaries, projects, departments, and work tickets.

## Features

- Role-based Admin, Manager, and Employee workflows
- Employee record management
- Salary management
- Project and ticket management
- Employee authentication
- Department and employee dashboards
- Project progress and ticket status tracking

## Technology

C#, Windows Forms, and SQL Server.

## Purpose

EMS is a practical desktop business application demonstrating database-driven employee and project management.
